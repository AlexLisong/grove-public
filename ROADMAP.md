# Roadmap

Grove is early-stage software. These are directions for discussion, not delivery commitments.

- Make first-run setup and provider errors easier to understand.
- Improve keyboard accessibility and small-screen editing.
- Add resumable imports and clearer export progress.
- Expand embedded table editing and PDF reading fidelity.
- Strengthen provider-specific tests with authorized, synthetic fixtures.
- Improve workflow evidence, recovery and human review.

See the [coverage ledger](docs/feature-coverage.md) for concrete implementation gaps. Good initial contributions include a reproducible bug report, a focused accessibility improvement, a setup-guide correction, or a regression test for a documented edge case. Discuss a broad feature or new provider before starting a large change.

# Community code of conduct

Help make Grove welcoming and useful. Treat people with respect, give constructive feedback, credit others' work and respect privacy. Harassment, threats, discrimination, sexualized conduct, doxxing and repeated personal attacks are not acceptable.

This applies to repository discussions, issues, pull requests and other spaces used to represent the project. Maintainers may edit or remove harmful content, limit participation or ban repeat offenders. Decisions should be proportionate and protect affected people.

For public moderation needs, flag the content with GitHub's reporting controls. To request private maintainer contact, open an issue titled “Private conduct contact requested” with no incident details or personal information; wait for a private channel before sharing the report. Do not post allegations or private evidence publicly. GitHub's own abuse-reporting process remains available for platform violations.

Maintainers should explain moderation decisions when safe to do so and consider new information or an appeal through the same private channel.
